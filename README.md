# MYP-Personal-Project-2025
A chatbot capable of reading PDF files, and giving summaries, answering questions, all while quoting information sources, not hallucinating, and looking stunning.

## Stack:
**Backend**:
<br>Language: Python
<br>Libraries:
- streamlit
- pdf_reader (self-made)
- sentence_transformers
- faiss
- numpy
- PyPDF2
- google
- google.genai
- whisper
- fpdf

LLM Api: Google Gemini

**Frontend**:
Framework: Streamlit + JS
UI: Streamlit + CSS
API Handling: Streamlit
