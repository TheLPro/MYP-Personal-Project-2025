# MYP-Personal-Project-2025
A chatbot capable of reading PDF files, and giving summaries, answering questions, all while quoting information sources, not hallucinating, and looking stunning.

## Stack:
**Backend**:
Language: Python
Libraries:
- PyPDF2
- pdf2image
- pytesseract
- nltk
- spacy
- sentence-transformers
- faiss
- httpx
- pydantic
- uvicorn

LLM Api: OpenAI API or Hugging Face Inference API
DB: SQLite

**Frontend**:
Framework: Next.js
UI: Tailwind CSS
API Handling: Axios, React Query
